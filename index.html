4단계 · 안전 준비

체험 종류에 맞는 안전수칙 확인

아래 종목을 누르면 해당 활동의 수칙이 표시됩니다.

🏄 서핑 안전수칙

  • ✓ 처음에는 강사의 지도를 받습니다.
  • ✓ 다른 서퍼와 충분한 거리를 유지합니다.
  • ✓ 지정된 구역 밖으로 나가지 않습니다.
  • ✓ 파도가 강해지면 즉시 활동을 중단합니다.

🛶 카약 안전수칙

  • ✓ 구명조끼를 체형에 맞게 착용합니다.
  • ✓ 카약에서 갑자기 일어서지 않습니다.
  • ✓ 동행자와 너무 멀리 떨어지지 않습니다.
  • ✓ 전복 시 혼자 무리하게 세우지 않습니다.

🏄‍♀️ 패들보드 안전수칙

  • ✓ 보드와 몸을 잇는 리시를 착용합니다.
  • ✓ 바람 방향과 세기를 확인합니다.
  • ✓ 처음에는 무릎 자세로 연습합니다.
  • ✓ 힘들면 보드 위에서 도움을 요청합니다.

⛵ 요트·보트 안전수칙

  • ✓ 승선 직후 비상장비 위치를 확인합니다.
  • ✓ 난간 밖으로 몸을 내밀지 않습니다.
  • ✓ 선장의 안내 없이 자리를 이동하지 않습니다.
  • ✓ 멀미나 이상 증상을 즉시 알립니다.
